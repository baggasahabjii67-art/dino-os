# Manga Reader

This repository is now only a focused manga-reader website. The Dino OS shell, game, extensions, and unrelated screens are no longer part of the application.

The app has exactly three main sections:

1. **Manga** — searchable manga library and chapter reader.
2. **History** — read chapters and saved progress, with clear-history support.
3. **Reader settings** — reading direction, image fitting, theme, and preload preferences.

Open a chapter and select **Download / Save PDF** to use the browser print dialog's **Save as PDF** option for the complete chapter. Library, history, and settings are stored locally in the browser.
